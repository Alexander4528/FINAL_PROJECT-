# Blog Platform

Полнофункциональная платформа для ведения блога с React фронтендом и Node.js бэкендом.(Я ОЧЕНЬ РАЗОЧАРОВАН!!!)

## 📋 Функциональность

### Бэкенд (Node.js + Express + PostgreSQL)
- Аутентификация и авторизация (JWT)
- CRUD операции для постов и комментариев
- Полнотекстовый поиск
- Лайки и избранное
- Пагинация и фильтрация
- Валидация данных
- Кэширование Redis
- Ролевая система (USER/ADMIN)

### Фронтенд (React + TypeScript)
- Регистрация и вход
- Создание/редактирование постов
- Комментарии и лайки
- Поиск постов и пользователей
- Профиль пользователя
- Избранные посты
- Адаптивный дизайн
- Темная/светлая тема
